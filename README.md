# resazurin_assay
Robert's lab resazurin assay with oysters data

On October 20th, 2026, I measured the length of each oyster shell from the "control #1", "low H2O2 #1" and "high H2O2 #1" groups. There were 5 oysters from each group. I placed the oysters in cups labeled 1-15 and submerged them in a resazurin solution. I started the resazurin assay at 12pm and pipetted 2mL from each cup into a 96-well plate every 30 minutes, keeping the oysters in an incubator set to 36 degrees Celsius. After the resazurin pipetting was finished, I ran plates "C" and "D" in a spectrophotometer which measures the fluorescence of each sample. 
I repeated this experiment on October 21st, 2026, with the #2 and #3 groups and then ran plates "F", "E", "G", and "H" in the spectrophotometer.
